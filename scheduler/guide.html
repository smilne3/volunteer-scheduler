How to use the volunteer scheduler

The scheduler drafts each week's shift calendar from the sign-up spreadsheet. You check it, change anything you like, and approve it. It never emails or texts anyone: telling volunteers is up to you.

What's in this folder

FileWhat it's for
Volunteer Scheduler.commandDouble-click to start. Opens a menu with everything below.
Draft next week.commandA shortcut: double-click to draft next week straight away.
Set up this Mac.commandDouble-click once on each Mac before using the scheduler there (it needs the internet), and again to get updates.
signups.xlsxThe latest sign-up spreadsheet. You replace it each week.
availability_review.csvWhere you confirm availability that people typed instead of ticking boxes.
weeks folderOne folder per week, holding review.html (the one-page check), assignments.csv (who's on each shift, editable) and, once approved, calendar.ics (for Google Calendar).
settings.jsonClosed dates and a few other settings. Ask before changing it.

Each week

  1. Update the sign-ups. In Google Sheets, open the sign-up responses and choose File → Download → Microsoft Excel (.xlsx). It lands in your Downloads folder under the sheet's name. Move it into this folder and rename it signups.xlsx, replacing the old one. The spreadsheet needs both tabs: Form Responses 1 and Shifts. In the Shifts tab, the experienced column says how many experienced volunteers each shift needs: Yes (one), No, or a number like 2 for a shift people often drop.
  2. Double-click "Volunteer Scheduler.command". A Terminal window opens with a numbered menu. Type a number and press Return. When you're finished, type q.
  3. Choose 1, Check the sign-ups. If it lists anyone under NEEDS READING, they typed their availability, and they won't be scheduled until you confirm what it means:
    • Open availability_review.csv (choose 5 to open this folder).
    • For each row, read the answer and the notes, then copy the suggested_reading into confirmed_reading, or write your own (see how to write a reading). Leave it blank if you're not sure: that person just won't be scheduled yet.
    • Save it as CSV. In Numbers, use File → Export To → CSV. In Excel, use File → Save and keep the CSV format.
    • Choose 1 again. Each row's status shows confirmed, or explains what to fix.
  4. Choose 2, Draft a week. Press Return for next week, or type a date like 11/16. The review page opens in your browser. Read Needs your attention first: any short shift is in red, with the reason.
  5. Change anything you want to (optional). Open weeks/<the week>/assignments.csv. Each row is one person on one shift. You can swap someone (change the name and email), remove a row, or fill a blank row (blank rows are open spots). A name on its own is fine if it matches one volunteer. Save it as CSV, then choose 3, Re-check a week. The review page refreshes and tells you if anything breaks a rule, for example someone who isn't available that day.
  6. Choose 4, Approve a week. If a rule is broken, it won't approve and tells you why. If a shift is short, type yes to approve anyway. Finder opens with calendar.ics selected, and the review page's banner turns green.
  7. Add it to Google Calendar. On a computer (the phone app can't import), open Google Calendar, click the gear, then Settings → Import & export → Import. Select calendar.ics, choose the volunteer-shifts calendar (not your personal one), and click Import. Nobody gets an invitation.
  8. Tell the volunteers yourself. The review page has a contact list with the phone and email of everyone scheduled. Nothing has been sent to anyone.
Changed your mind after approving? Edit that week's assignments.csv, choose 3, then 4. If you'd already imported the week into Google Calendar, delete that week's shift events there first, then import the new calendar.ics, so nothing is doubled.

How to write a reading

Shift IDs are the day plus start time, for example SAT-0900 for Saturday 9 am. Option 1 lists them at the top.

ReadingMeans
SAT-0900, SAT-1200Both Saturday shifts, every week
SAT-0900, SAT-1200 except 2026-11-14Every Saturday except Nov 14
WED-1700 only 2026-11-11, 2026-11-25Phone bank on those two dates only
SAT-0900; WED-1700 only 2026-11-11Saturday mornings every week, plus phone bank on Nov 11 only
noneNo shifts

The suggestions leave out anything uncertain, like "maybe Saturdays" or "every other week", and the notes say why. For "every other week", the notes offer both possible sets of dates, ready to copy.

If something goes wrong

"…isn't downloaded to this Mac yet"
In Finder, right-click the file and choose Download Now, then try again.
"…looks open in Excel"
Close the file in Excel or Numbers, then try again.
"There's already a draft for that week"
Press Return to keep it (choose 3 to check your edits), or type yes for a fresh draft. The old one is kept as a copy in the week's folder.
"…is already approved"
Edit that week's assignments.csv, choose 3, then 4 to approve it again.
"…missing these column headings" or "no sheet named…"
A tab or question in the spreadsheet was renamed. The message lists what it expected. Rename it back and download again.
macOS says the .command file can't be opened
Right-click it, choose Open, then Open again. You only need to do this once.
"The scheduler isn't set up on this Mac yet"
Double-click Set up this Mac.command once. If it asks to install Apple's command line developer tools, click Install, wait, then double-click it again.
